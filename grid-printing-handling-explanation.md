# Data Grid Printing Handling - Comprehensive Guide

## Overview

The MUI X Data Grid provides sophisticated printing functionality that allows users to print grid data with full customization options. The printing system is designed to handle complex scenarios including large datasets, custom styling, cross-browser compatibility, and various export configurations.

## Architecture Overview

### Core Components

1. **`useGridPrintExport` Hook** - Main orchestrator of print functionality
2. **Utility Functions** - Helper functions for column/row selection and data processing
3. **Print Window Management** - iframe-based isolated print environment
4. **Style System** - CSS and style management for print output
5. **State Management** - Grid state backup and restoration
6. **UI Integration** - Export menu and toolbar integration

## Print Process Flow

### 1. **Initialization Phase**

When a user initiates a print export:

```typescript
// User clicks print button or calls API
apiRef.current.exportDataAsPrint(options);
```

**Steps**:
- Validate grid root element exists
- Save current grid state for restoration
- Log debug information
- Check for required dependencies

### 2. **State Preparation Phase**

The grid undergoes several transformations to prepare for printing:

#### a) **State Backup**
```typescript
// Complete grid state snapshot
previousGridState.current = apiRef.current.exportState();

// Column visibility backup
previousColumnVisibility.current = gridColumnVisibilityModelSelector(apiRef);

// Row data backup (excluding auto-generated rows)
previousRows.current = apiRef.current
  .getSortedRows()
  .filter((row) => !row[GRID_ID_AUTOGENERATED]);
```

#### b) **Pagination Adjustment**
```typescript
if (props.pagination) {
  const visibleRowCount = gridExpandedRowCountSelector(apiRef);
  // Set to show all rows on page 0
  const paginationModel = { page: 0, pageSize: visibleRowCount };
  // Update pagination state
}
```

#### c) **Virtualization Disable**
```typescript
// Disable both row and column virtualization
apiRef.current.setState((state) => ({
  ...state,
  virtualization: {
    ...state.virtualization,
    enabled: false,
    enabledForColumns: false,
  },
}));
```

**Why virtualization is disabled**:
- Virtualization only renders visible items for performance
- Print needs all data rendered simultaneously
- Ensures complete data capture for printing

### 3. **Data Filtering Phase**

#### Column Filtering
```typescript
await updateGridColumnsForPrint(
  options?.fields,      // Specific columns to include
  options?.allColumns,  // Include hidden columns
  options?.includeCheckboxes // Include selection checkboxes
);
```

**Column Selection Logic**:
1. If `fields` specified → Use only those columns
2. If `allColumns` true → Include all columns (including hidden)
3. If `allColumns` false → Use only visible columns
4. Filter out columns with `disableExport: true`
5. Optionally include checkbox selection column

#### Row Filtering
```typescript
updateGridRowsForPrint(
  options?.getRowsToExport ?? defaultGetRowsToExport
);
```

**Default Row Selection Logic** (`defaultGetRowsToExport`):
```typescript
export const defaultGetRowsToExport = ({ apiRef }) => {
  const filteredSortedRowIds = gridFilteredSortedRowIdsSelector(apiRef);
  const rowTree = gridRowTreeSelector(apiRef);
  const selectedRowsCount = gridRowSelectionCountSelector(apiRef);
  
  // Get body rows (exclude footers)
  const bodyRows = filteredSortedRowIds.filter((id) => 
    rowTree[id].type !== 'footer'
  );
  
  // Add pinned rows
  const pinnedRows = gridPinnedRowsSelector(apiRef);
  const topPinnedRowsIds = pinnedRows?.top?.map((row) => row.id) || [];
  const bottomPinnedRowsIds = pinnedRows?.bottom?.map((row) => row.id) || [];
  
  bodyRows.unshift(...topPinnedRowsIds);
  bodyRows.push(...bottomPinnedRowsIds);
  
  // If rows are selected, export only selected rows
  if (selectedRowsCount > 0) {
    const selectedRows = gridRowSelectionIdsSelector(apiRef);
    return bodyRows.filter((id) => selectedRows.has(id));
  }
  
  return bodyRows;
};
```

### 4. **Print Window Creation Phase**

#### iframe Creation

### 6. **Styling Phase**

#### Style Sheet Copying
The grid uses a sophisticated style copying mechanism:

```typescript
// Determine style source (document or shadow DOM)
const rootCandidate = gridRootElement!.getRootNode();
const root = rootCandidate.constructor.name === 'ShadowRoot'
  ? (rootCandidate as ShadowRoot)
  : document;

// Copy all stylesheets
const stylesheetLoadPromises = loadStyleSheets(printDoc, root);
```

**`loadStyleSheets` Function Details**:
```typescript
export function loadStyleSheets(document: Document, root: Document | ShadowRoot) {
  const stylesheetLoadPromises: Promise<void>[] = [];
  const headStyleElements = root.querySelectorAll("style, link[rel='stylesheet']");

  for (let i = 0; i < headStyleElements.length; i++) {
    const node = headStyleElements[i];
    
    if (node.tagName === 'STYLE') {
      // Copy inline styles
      const newStyleElement = document.createElement(node.tagName);
      const sheet = (node as HTMLStyleElement).sheet;
      
      if (sheet) {
        let styleCSS = '';
        for (let j = 0; j < sheet.cssRules.length; j++) {
          styleCSS += `${sheet.cssRules[j].cssText}\r\n`;
        }
        newStyleElement.appendChild(document.createTextNode(styleCSS));
        document.head.appendChild(newStyleElement);
      }
    } else if (node.getAttribute('href')) {
      // Copy external stylesheets
      const newLinkElement = document.createElement(node.tagName);
      
      // Copy all attributes
      for (let j = 0; j < node.attributes.length; j++) {
        const attr = node.attributes[j];
        newLinkElement.setAttribute(attr.nodeName, attr.nodeValue || '');
      }
      
      // Wait for stylesheet to load
      stylesheetLoadPromises.push(
        new Promise((resolve) => {
          newLinkElement.addEventListener('load', () => resolve());
        })
      );
      
      document.head.appendChild(newLinkElement);
    }
  }
  
  return stylesheetLoadPromises;
}
```

#### Safari Compatibility Workaround

### 8. **Print Execution Phase**

```typescript
// Wait for all stylesheets to load
Promise.all(stylesheetLoadPromises).then(() => {
  // Trigger browser print dialog
  printWindow.contentWindow!.print();
});
```

### 9. **Cleanup and Restoration Phase**

#### Print Completion Detection
```typescript
// Monitor print media query to detect completion
const mediaQueryList = printWindow.contentWindow!.matchMedia('print');
mediaQueryList.addEventListener('change', (mql) => {
  const isAfterPrint = mql.matches === false;
  if (isAfterPrint) {
    handlePrintWindowAfterPrint(printWindow);
  }
});
```

#### State Restoration
```typescript
const handlePrintWindowAfterPrint = (printWindow: HTMLIFrameElement) => {
  // Remove print iframe
  document.body.removeChild(printWindow);
  
  // Restore complete grid state
  apiRef.current.restoreState(previousGridState.current || {});
  
  // Restore column visibility (if not in main state)
  if (!previousGridState.current?.columns?.columnVisibilityModel) {
    apiRef.current.setColumnVisibilityModel(previousColumnVisibility.current);
  }
  
  // Re-enable virtualization
  apiRef.current.setState((state) => ({
    ...state,
    virtualization: previousVirtualizationState.current!,
  }));
  
  // Restore original rows
  apiRef.current.setRows(previousRows.current);
  
  // Clear references to prevent memory leaks
  previousGridState.current = null;
  previousColumnVisibility.current = {};
  previousRows.current = [];
};
```

interface GridPrintExportOptions extends GridExportOptions {

## Cross-Browser Considerations

### Safari-Specific Issues
- **Clone Isolation Bug**: Direct DOM node cloning fails in print context
- **Workaround**: Use innerHTML copying instead of direct appendChild

### Chrome-Specific Issues  
- **Print Dialog Layout**: CSS containment property needed for proper layout
- **Empty Page Prevention**: Body margin reset required

### Firefox Considerations
- **Stylesheet Loading**: Different timing for external stylesheet loading
- **Print Preview**: Different print preview behavior

### Edge Cases Handled
1. **Shadow DOM**: Special handling for components using Shadow DOM
2. **Dynamic Stylesheets**: Proper copying of runtime-generated styles
3. **Large Datasets**: Memory management for very large grids
4. **Responsive Layouts**: Proper sizing calculations for different screen sizes

## Performance Considerations

### Memory Management
- **State Snapshots**: Efficiently store and restore large state objects
- **Reference Cleanup**: Clear all references after printing to prevent leaks
- **iframe Removal**: Properly dispose of print iframe after completion

### Virtualization Impact
- **Temporary Disable**: Virtualization must be disabled during print preparation
- **Performance Cost**: Large datasets may cause temporary performance impact
- **Restoration**: Virtualization is re-enabled after printing

### Asynchronous Operations
- **State Updates**: Use requestAnimationFrame to ensure DOM updates
- **Stylesheet Loading**: Wait for external stylesheets before printing
- **Print Detection**: Use media queries for print completion detection

## Integration with Grid Features

- Integrates with row selection state

- Respects current filter state

- Temporarily adjusts pagination to show all data

- Restores original pagination after printing
